# Dijkstra Maze — TODO Quest (웹 버전) 안내

학생이 `student/` 폴더를 직접 뒤져서 TODO를 찾는 대신, 한 페이지짜리 웹사이트에서
**38개 코드 칸**(Required 8 + Bonus 30)을 한 단계씩 풀 수 있게 만든 결과물입니다.

> **Bonus는 이제 한 화면에 여러 칸이 쌓이지 않습니다.** 예전에는 사이드바에서 "TODO 8"을
> 누르면 편집기 6개가 한꺼번에 세로로 쌓여서, 학생이 무엇부터 손대야 할지 알 수 없었습니다.
> 지금은 그 파트 하나하나가 **각자 사이드바 항목을 가진 독립 단계**(`8-1` … `11-4`)이고,
> 한 단계는 **파일 하나 · 코드 칸 하나 · 힌트 하나**입니다. 보통 1~3줄이에요.
>
> 잠금 규칙: **묶음(6번대·7번대·8번대·9번대)끼리는 순서 자유**, **한 묶음 안에서는 순서대로**
> (앞 단계를 완료하거나 Skip해야 다음 단계가 열립니다). 9번대는 잠금 대상이 아닙니다.
>
> 묶음별 단계 수: **6번대 8 · 7번대 12 · 8번대 6 · 9번대 4 = 30개.**
> 빨리 끝내는 학생용으로, 원래 코드에 **고정값으로 박혀 있던** 설정 6개를
> (미로 생성 애니메이션, 힌트 경로의 폭탄 회피 가중치, 폭발 그림, 그리고 화면·정보판·
> 상태 메시지 색 세 묶음) 각각 작은 단계로 꺼냈습니다. 새 기능이 아니라 **원래 있던 값**입니다.

학생이 "Run my code"를 누르면 **자기 코드를 Pyodide로 실제 실행한** 결과를
애니메이션·미리보기로 보여줍니다. 미리 만들어둔 정답 애니메이션이 아닙니다.

  수업을 시작하세요. 스프라이트 · 픽업 사운드 · 서로 다른 아이템 3종 · 2라운드가 돌아갑니다.

## 1. 실행 방법

1. `dijkstra_maze_web` 폴더를 통째로 학생에게 배포합니다 (또는 배포된 주소를 알려줍니다).
2. **`로컬서버_실행.bat`을 더블클릭**하면 `python -m http.server 8000` 이 뜨고
   브라우저가 `http://localhost:8000` 을 엽니다. 창을 닫으면 서버가 꺼집니다.
3. 파이썬이 없으면 배치 파일이 설치 안내를 띄웁니다
   (python.org 설치 시 "Add python.exe to PATH" 체크 필요).
4. `index.html`을 그냥 더블클릭해도 페이지는 뜨지만 `file://` 경고 배너가 뜹니다.
   채점과 이미지·소리 업로드는 `file://` 에서도 동작합니다.
5. **인터넷 연결이 필요합니다** — Pyodide를 CDN에서 최초 1회 내려받습니다.
   학교 방화벽이 막는 경우가 있으니 수업 전 최소 1대에서 "Run my code"를 눌러보세요.

## 5. 채점 방식

- **behaviour 모드**: 학생 코드를 격리된 미니 테스트 환경에 끼워 넣고 **행동만** 비교합니다.
  변수 이름이나 코드 구조가 달라도 결과가 같으면 통과합니다.
- **Bonus는 "안 터지면 통과"** 가 원칙입니다. 게임을 플레이 불가능하게 만드는 것만
  오답이고(예외 발생, 잘못된 타입, 목표에서 멀리 있는데 클리어), 나머지는 전부 경고입니다.
- **무한 루프를 써도 브라우저가 멈추지 않습니다.** 모든 학생 코드 호출은 실행량을 세는
  가드를 거치고, 예산을 넘기면 "loop that never ends"라는 채점 실패로 바뀝니다.
- 채점 하네스는 정답을 담고 있지 않습니다 — 몇 가지 입력에 대한 기대 **결과**만 확인합니다.

### 수업 중 나올 수 있는 "게임이 안 돌아가요" 3가지

1. **움직임이 너무 느림/빠름** — TODO 8-2의 `PLAYER_MOVE_DELAY_MS`.
   `5000` 처럼 터무니없는 값을 넣으면 채점기가 경고하지만 **통과는 시킵니다**(개방형 원칙).
2. **라운드를 절대 못 깸** — TODO 11-3에서 "아이템 전부 수집" 조건을 넣었는데
   아이템이 0개인 라운드가 있는 경우. 역시 경고합니다.
3. **아이템 효과가 무한히 쌓임** — TODO 10-4에서 `item.active = False` 누락. 오답 처리됩니다.
4. **10-5·10-6에서 들여쓰기 오류** — 이 두 단계는 10-4가 연 `if` **안쪽**에 들어갑니다.
   10-4의 `for`/`if` 두 줄을 지우면 다음 단계가 문법 오류가 납니다.

## 6. 테스트 (코드를 고쳤다면 반드시 재실행)

```
node   tests/test_app_load.js              # 가장 빠름. 세 가지 모드 부팅 + 단계/마커 정합성 + 잠금 규칙
node   tests/test_project_export.js        # zip 파일 목록 + 정답 splice 후 실제 파이썬 실행
node   tests/test_board_sizing.js          # Play 보드 캔버스 크기 (키오스크·전체화면·리사이즈)
python tests/test_alt_implementations.py   # 채점 하네스 회귀 (동등 구현 / 오답 통제군)
python tests/test_trace_harnesses.py       # Play 탭·시각화 미리보기 경로 (느림)
python tests/test_fuzz_harnesses.py        # 온갖 이상한 학생 코드로 하네스 공격 (오래 걸림)
```

`tests/extract_harnesses.py` 는 **실제 `app.js`에서 하네스 생성 함수를 그대로 추출해서**
돌립니다 — 손으로 다시 타이핑한 대역이 아니라 진짜 배포되는 로직을 검증합니다.

### 자동 생성 파일 — 손으로 고치지 마세요

파이썬 원본(`dijkstra_maze/student/*.py`, `complete/*.py`)이나 `data.js` 를 고쳤다면
아래를 **반드시** 다시 돌리세요. 생성기는 이제 저장소 안(`scripts/`)에 있습니다.

```
node scripts/gen_export_data.js   # student/*.py  -> export-data.js
node scripts/gen_answers.js       # complete/*.py -> answers.html + 교사용/정답_해설.md
node scripts/gen_todos.js         # data.js       -> dijkstra_maze/todos.json
```

`gen_answers.js` 는 정답 코드를 **항상 `complete/*.py` 에서 직접 뽑습니다** — 한국어 해설만
`scripts/answer_notes.json` 에 손으로 적혀 있으므로, 정답이 실제 코드와 어긋날 수 없습니다.
`0924` 게이트는 그대로 유지됩니다.

## 7. 진행 상황 저장 / 제출물

- 자동으로 `localStorage`에 저장됩니다 (코드 초안, 완료·스킵 상태, 힌트 사용, 시도 횟수,
  맵 에디터로 그린 지도, 업로드 파일 목록).
- 여러 학생이 같은 컴퓨터를 쓰면 상단의 **"Save my work" / "Load my work"** 를 안내하세요.
- 제출물은 **두 가지를 함께** 받으세요: `progress.json`("Save my work") +
  **"Download my project"** zip(실제로 실행되는 파이썬 프로젝트).
  학생이 직접 업로드한 이미지·소리도 zip의 `assets/` 에 자동으로 들어갑니다.
- 단, 업로드한 파일 자체는 `progress.json` 에는 없고 **그 브라우저에만** 저장됩니다.
  다른 컴퓨터에서 이어서 하려면 다시 업로드해야 합니다 (zip 제출을 함께 받는 이유).
- 단계 구조가 바뀌어도 저장된 진행 상황은 살아남습니다 — 파트가 늘어난 단계는
  이미 쓴 파트를 그대로 두고 새 파트만 스타터 코드로 채웁니다.
